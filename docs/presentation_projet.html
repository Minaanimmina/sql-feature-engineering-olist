Le projet

Olist est une marketplace brésilienne connectant petits commerçants et clients finaux. Le dataset couvre ~100 000 commandes entre 2016 et 2018.

Qu'est-ce que le churn ?

Le churn désigne la perte de clients. Un client churne quand il cesse d'acheter et ne revient pas.

"Quels clients vont churner dans les 90 prochains jours, et quels signaux comportementaux les distinguent des clients fidèles ?"

SQL Avancé

Les CTEs — Common Table Expressions

-- Sous-requête
SELECT * FROM (
  SELECT customer_unique_id, COUNT(*) AS nb_commandes
  FROM orders GROUP BY customer_unique_id
) sub WHERE sub.nb_commandes > 3;
-- CTE
WITH commandes AS (
  SELECT customer_unique_id, COUNT(*) AS nb_commandes
  FROM orders GROUP BY customer_unique_id
)
SELECT * FROM commandes
WHERE nb_commandes > 3;

C'est quoi ? Une CTE est une sous-requête nommée. On la calcule une fois, on l'utilise ensuite comme une table normale.

Pourquoi ?

Lisibilité
Chaque CTE fait une seule chose. On sait exactement ce qu'elle calcule.

Réutilisabilité
On peut la joindre plusieurs fois.

Débogage
On peut tester chaque CTE séparément.

Churn & Segmentation

Comment on définit "churné" ?

Le seuil n'est pas arbitraire. Il a été calibré par analyse des taux réels sur le dataset.

Seuil testé Taux de churn
90 jours 90% ✗ tout le monde churne
180 jours 71% ✗ trop élevé
270 jours 49%
365 jours ✓ 29% retenu

Limite connue : ~97% des clients n'ont commandé qu'une seule fois. Distinction churné / client unique difficile.
